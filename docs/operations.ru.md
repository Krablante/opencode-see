## Установка и обновление

Установка описана в [README](../README.ru.md#установка). Загрузчик хоста запускает
плагин из исходника TypeScript. Сборка, контейнер, демон и отдельный выпускной
пайплайн не нужны. `package-lock.json` фиксирует дерево зависимостей;
`npm ci --omit=dev` ставит только зависимости выполнения. Пометка private
защищает от публикации в npm; код остаётся открытым под лицензией MIT.

Обновление чистого клона:

```bash
git pull --ff-only
npm ci --omit=dev
```

После этого перезапусти OpenCode либо OpenCodez. Загруженный плагин продолжает
работать со старым кодом. Для фиксированной установки выбери опубликованный
Git-тег вместо отслеживания `main`. Перед обновлением проверь
[релизы](https://github.com/Krablante/opencode-see/releases) и
[историю изменений](../CHANGELOG.ru.md). Для отката верни выбранную предыдущую
ревизию, повтори установку зависимостей и перезапуск.

В управляемой установке используй существующий механизм развёртывания: перенеси
`src/`, `package.json` и `package-lock.json`, поставь зависимости и перезапусти
нужный хост. Убедись, что копия исходников совпадает с выбранной ревизией.
Обновление не должно заменять каталог с пользовательскими настройками или
снимками.

## Установка браузера

Браузер на Chromium нужен только для `screenshot`. Прямой выбор через
`chromiumPath` / `OPENCODE_SEE_CHROMIUM` проверяется первым; ошибка не подменяется
другим браузером. Без него проверяются `chromium-browser`, `google-chrome`,
Linux-запускники Snap и `chromium`, затем обычные пути Chrome в macOS и Windows
и Edge в Windows Program Files.

| Система | Установка |
| --- | --- |
| Debian | `sudo apt install chromium` |
| Ubuntu | `sudo snap install chromium` либо пакет дистрибутива `chromium-browser` |
| Fedora | `sudo dnf install chromium` |
| macOS | Установить Google Chrome |
| Windows | Использовать Microsoft Edge либо установить Google Chrome |

Задай `OPENCODE_SEE_CHROMIUM`, если браузер находится в другом месте. Запускай
OpenCode от обычного пользователя. Плагин не отключает песочницу Chromium для
запуска от root или в контейнере. Ошибка запуска браузера возвращается из
попытки захвата.

## Хранение и таймауты

Скриншоты остаются в каталоге назначения до удаления. Не включай рабочие снимки
в Git и выбери подходящий срок хранения. Плагин не запускает фоновую очистку.
Браузерные профили временные и удаляются после захвата; для Snap используется
доступное ему пользовательское хранилище.

Нативная передача картинки не добавляет запрос к модели. Делегирование добавляет
одну сессию и расход у провайдера. По умолчанию сессия удаляется;
`deleteAfter: false` сохраняет картинки и текст у хоста. История чата и нативные
вложения также подчиняются обычной политике хранения OpenCode.

Начальный срок захвата — 30 секунд на CDP и CLI вместе. Для Snap перехода на
CLI нет. Таймаут и отмена останавливают захват без повтора. Браузер завершается
до возврата результата, что иногда добавляет короткую задержку. Таймаут делегата
в 90 секунд покрывает создание сессии и ответ. Запросы серверной остановки и
удаления имеют отдельные интервалы очистки до 10 секунд каждый.

## Устранение проблем

| Симптом | Что проверить |
| --- | --- |
| Модель не увидела картинку | Нативную поддержку, точный маршрут `forceFor`, блок `Vision via` либо сообщение об ошибке |
| Делегат вернул ошибку | Точный ID модели, авторизацию провайдера и поддержку картинок; доступ к начальной Go-модели не гарантирован |
| Картинка из чата не найдена | Вызови `image_view` без путей; подходят только поддерживаемые data URL текущей сессии |
| Неожиданный запрос разрешения | Канонический путь в метаданных: цель симлинка может быть вне рабочего дерева |
| Браузер не найден | Установку браузера либо прямой путь к нему |
| Ошибка Snap CDP | Хранилище пользователя Snap и доступ к loopback-отладке; переход на CLI отключён намеренно |
| Не снялось позднее содержимое | Увеличь `virtualTimeBudgetMs`; при необходимости увеличь общий таймаут захвата |
| Захват истекает по времени | Один срок покрывает обе попытки; медленный или недоступный URL способен израсходовать его до CLI |
| Выходной файл уже существует | Выбери новое имя: перезапись запрещена |
| При загрузке плагина ошибка `paths.filter` | Обновись до 0.4.1 или новее и перезапусти: старые экспорты мешали загрузчику |

Ошибки настройки указывают соответствующее поле либо путь. Приоритеты и все
переменные описаны в [настройке](./configuration.ru.md).

## Проверка

Для разработки поставь все зависимости через `npm ci` и выполни `npm run check`.
Существующий набор проверяет маршруты, извлечение картинок, разрешения,
конфигурацию и жизненный цикл захвата. CI запускает ту же команду на Node.js 22.

После обновления рабочей установки загрузи плагин в новой сессии хоста.
Проверь локальную картинку и вложение чата на нативной vision-модели, затем
текстовую или принудительно направленную модель с конкретным вопросом. После
правки браузера сними небольшую локальную страницу, посмотри готовый PNG и
убедись, что отмена не оставляет браузер или временный профиль. Одних модульных
тестов для подтверждения работы живой установки недостаточно.
