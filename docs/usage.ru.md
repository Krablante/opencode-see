# Использование

[English](./usage.md) · [Русский](./usage.ru.md) · [Главная](../README.ru.md)

## Открыть локальные картинки

`image_view` принимает от одного до пяти уникальных путей. Относительные пути
считаются от активного каталога OpenCode; абсолютные пути и `~/` тоже работают.
Инструмент разрешает симлинки и запрашивает разрешение на чтение. Если цель
находится вне рабочего дерева, сначала нужно разрешение `external_directory`.

```json
{
  "paths": ["./diagram.png", "~/Pictures/reference.webp"],
  "question": "Что изменилось между этими двумя раскладками?"
}
```

Поддерживаются PNG, JPEG, WebP и GIF размером до 20 MiB каждый. Формат и размеры
определяются по байтам, а не по имени. Плагин читает заголовки, а не декодирует
все пиксели: повреждённая картинка всё ещё может вызвать ошибку у хоста или
провайдера. PDF и URL удалённых изображений не поддерживаются.

## Использовать картинки из чата

Не передавай `paths`, чтобы посмотреть последнюю группу изображений текущей
сессии:

```json
{ "question": "Какой точный текст ошибки виден?" }
```

Это равнозначно `source: "latest"`. Группа берётся из файловых частей сообщения
пользователя либо одного завершённого результата инструмента. Порядок сохраняется;
возвращается до пяти уникальных поддерживаемых картинок. Для сравнения недавних
картинок из нескольких групп используй `source: "session"`. Более новые группы
идут первыми:

```json
{ "source": "session", "question": "Как менялась раскладка?" }
```

`paths` и `source` нельзя передать вместе. Поиск принимает только сохранённые
data URL текущей сессии. Повреждённые, слишком большие и неподдерживаемые картинки
пропускаются. Удалённые URL вложений не загружаются. Эти байты не требуют нового
файлового разрешения.

## Снять страницу

`screenshot` открывает страницу в новом локальном профиле Chromium. Куки твоего
обычного браузера и уже открытые вкладки не используются.

```json
{
  "url": "http://localhost:3000",
  "output_path": "home.png",
  "width": 1440,
  "height": 900,
  "question": "Какие подписи трудно читать?"
}
```

Принимаются только HTTP и HTTPS. Начальный размер окна — 1440×900. Ширина и
высота — положительные целые числа; площадь ограничена 32 мегапикселями
(33 554 432 пикселя). Снимается видимая область страницы. `output_path` остаётся
внутри каталога скриншотов, в том числе при переходах через симлинки. Если
расширения нет, добавляется `.png`. Существующие файлы не заменяются. Без имени
создаётся файл с отметкой времени. Готовый PNG тоже должен уложиться в 20 MiB.

## Прочитать результат

Нативная vision-модель получает картинки и текстовые метаданные. Другие модели
получают метаданные, блок `Vision via <modelID>:` и ответ делегата. Необязательный
`question` дополняет базовый запрос делегату; на нативные вложения он не влияет.
Ошибка делегирования возвращается явно, без выдуманного описания.
[Настройка](./configuration.ru.md) управляет выбором маршрута.

Метаданные содержат имя или путь, объём в байтах, формат и размеры. Пометка
`core_resize=yes` основана на известных порогах хоста: больше 2000 пикселей по
любой стороне либо больше 5 MiB в base64. Плагин не уменьшает картинки; фактическая
обработка зависит от версии OpenCode и провайдера.

На совместимом хосте серверное сжатие контекста OpenAI посреди хода иногда
скрывает свежий результат инструмента. Плагин восстанавливает эту группу для
ближайшего продолжения. Настройка не нужна; повторные вложения существуют только
во входе модели. Точные границы описаны в [архитектуре](./architecture.ru.md).
