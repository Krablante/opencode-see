## Поддерживаемые версии

Исправления безопасности выпускаются для актуальной линии релизов.

## Сообщить об уязвимости

Не открывай публичный issue для ещё не исправленной уязвимости. Используй
приватное сообщение об уязвимости в GitHub Security Advisory этого репозитория.
Укажи:

- Версию с проблемой.
- Минимальный пример воспроизведения.
- Затронутую файловую или браузерную границу.
- Наблюдаемые последствия.

## Границы доверия

Плагин OpenCode работает от того же пользователя ОС, что и сам OpenCode.
Устанавливай только доверенный код. `opencode-see` запрашивает `read` для каждой
картинки и `external_directory` для целей вне рабочего дерева. Он не загружает
секреты провайдера и не вызывает API провайдера напрямую.

Для текстовой модели либо маршрута из `visionDelegate.forceFor` картинки
отправляются выбранному делегату через временную сессию OpenCode. За авторизацию
и транспорт отвечает сервер OpenCode. Выбор делегата определяет, куда попадут
данные; используй провайдера, которому доверяешь эти изображения.

При `source: "latest"` либо `"session"` читаются сохранённые сообщения только
вызывающей сессии. Принимаются поддерживаемые data URL из файловых частей
пользовательских сообщений и завершённых вложений инструментов. Сигнатуры байтов
проверяются, кэш не сохраняется. Плагин не перечисляет чужие сессии, не ищет
файлы и не загружает удалённые URL вложений. Новое файловое разрешение не нужно:
эти байты уже находятся в текущей сессии OpenCode.

`screenshot` запускает локальный браузер и принимает только HTTP и HTTPS.
Страница всё ещё может обращаться к сервисам, достижимым с этой машины.
Проверяй URL перед разрешением инструмента в недоверенной сессии.

Картинка ограничена 20 MiB, окно скриншота — 32 мегапикселями. Это снижает риск
случайного истощения ресурсов; проверка заголовков не заменяет полный декодер
или песочницу. Каталоги назначения проверяются после разрешения симлинков,
файлы создаются эксклюзивно. Настоящая граница безопасности — права файловой
системы и пользователь ОС, от которого работает хост.

У делегата отключены инструменты. При таймауте или отмене вызывается серверная
остановка перед возможным удалением. Ошибка очистки записывается в журнал,
а не считается успехом. Сохранённая сессия делегата и скриншот продолжают
содержать картинки; учитывай их в политике хранения.
