# История изменений

[English](./CHANGELOG.md) · [Русский](./CHANGELOG.ru.md) · [Главная](./README.ru.md)

Здесь собраны существенные изменения проекта.

## Ещё не выпущено

- Оба режима поиска картинок начинают с хвоста истории и расширяют окно только
  при необходимости. Поиск останавливается на нужной группе либо пяти недавних
  уникальных картинках. Декодируются только выбранные кандидаты; base64 не
  кодируется повторно.
- Картинки ограничены 20 MiB, локальные файлы читаются последовательно, отмена
  инструмента передаётся чтению файлов и сессии. Поддержаны короткие заголовки
  lossless WebP.
- В сессиях vision-делегата отключены инструменты. Таймаут и отмена останавливают
  выполнение на сервере даже при сохранении сессии. Частичный ответ вместе с
  ошибкой помощника не считается успехом. Отмена исходного вызова передаётся дальше.
  Подсказка текстовым моделям допускает `screenshot` для запроса страницы и
  направляет к `image_view` для существующих картинок.
- Проверяются типы объектов настройки и диапазоны таймеров. Имя настроенного
  делегата больше не считается доказательством поддержки картинок. Отмена
  передаётся проверке возможностей модели; чтение истории для восстановления
  после сжатия ограничено пятью секундами.
- Окно скриншота ограничено 32 мегапикселями, снимается видимая область,
  проверяются заголовки PNG. Симлинки не выводят запись за корень скриншотов.
  Исправлена проверка разрешений для дочерних путей, начинающихся с точек.
- Прямой выбор браузера не подменяется другим. Добавлены обычные пути Chrome
  в Windows.
- Руководство разделено на одинаковые английские и русские страницы использования,
  настройки, эксплуатации и архитектуры. README сокращён; руководство для
  разработчиков, безопасность и история версий получили локализации. Новые
  языки добавляются по общему правилу суффиксов.
- Пример конфигурации стал переносимым. Демонстрация явно показывает иллюстрации
  вызовов инструментов. Убрано хрупкое побайтовое сравнение медиа, ограничено
  число потоков их генерации.
- Пометка private запрещает публикацию пакета в npm. Убраны неиспользуемый
  падающий workflow публикации и отдельный скрипт установки, удалявший каталог.
  Поставка остаётся через GitHub и существующие механизмы оператора.

## 0.4.1 — 2026-09-16

- Функции разрешений вынесены из точки входа, чтобы загрузчик OpenCode не
  принимал их за инициализаторы плагина.
- Общий таймаут охватывает поиск CDP, навигацию, захват и резервный CLI.
  Отмена и истечение времени не запускают новую попытку.
- Ожидания команд и событий CDP завершаются при сбое соединения или закрытии.
  После неудачной навигации не остаются необработанные отклонения промисов.
- Завершение браузера ожидается, профили удаляются при успехе и ошибке. В Unix
  завершается вся группа процессов, включая переживших запускник детей.
  CLI получает свой профиль; оба способа создают выходной файл эксклюзивно.

## 0.4.0 — 2026-08-22

- Добавлен `visionDelegate.forceFor`: список точных `provider/model`, направляющий
  выбранные нативные модели через делегат. Текстовые модели делегируются автоматически.
- Принудительным маршрутам возвращается текст без картинок. Это обходит особенности
  обработки вложений провайдера без изменения ядра OpenCode или OpenCodez.
- Начальный маршрут сохранён: одна проверка точного совпадения, нативные картинки
  без дополнительного запроса к модели.

## 0.3.0 — 2026-08-20

- `image_view` находит последнюю группу либо до пяти недавних уникальных картинок
  текущей сессии из пользовательских вложений и завершённых инструментов.
- Необязательный `question` у обоих инструментов дополняет базовый запрос
  делегату и даёт текстовой модели ответ на конкретный визуальный вопрос.
- Подсказка для текстовых моделей направляет их к `image_view` вместо поиска
  файлов или догадок. Системные запросы нативных моделей не меняются.
- Поиск ограничен текущей сессией и data URL, проверяет сигнатуры, не хранит кэш
  и возвращает не больше пяти картинок.

## 0.2.0 — 2026-08-20

- Добавлено настраиваемое делегирование через временную сессию OpenCode.
  Текстовые модели получают описание картинки без секретов внутри плагина.
- Сохранён нативный маршрут без дополнительного запроса, введены явные ошибки
  выключенного или неудачного делегирования.
- Добавлены учёт возможностей модели, очистка сессии через SDK, таймауты,
  настройка делегата одной строкой со старой совместимостью, переменные окружения,
  тесты и английская/русская документация.
- Свежие картинки восстанавливаются после совместимого серверного сжатия
  посреди хода, без дополнительных запросов провайдера, кэша или постоянного
  состояния. Обычные пути OpenCode и локальных провайдеров не меняются.

## 0.1.0 — 2026-08-20

- `image_view` читает от одной до пяти локальных PNG, JPEG, WebP или GIF.
- Добавлены разрешения путей, определение MIME по сигнатуре, размеры и пометка
  ожидаемого уменьшения картинок хостом.
- Добавлен захват Chromium через CDP с лёгким резервным CLI.
- Добавлены переносимая настройка, английская и русская документация, тесты
  и воспроизводимые демонстрации.
